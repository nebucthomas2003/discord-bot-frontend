# PulseAPP Dashboard Frontend

Professional React dashboard for the PulseAPP Discord bot. View command history, authenticate with admin credentials, and monitor bot activity in real-time.

## Features

- 🔐 Secure admin login with session management
- 📊 Real-time command history display
- ⚡ 30-second caching for efficient data fetching
- 🎨 Responsive, professional UI with error handling
- 🔄 Automatic data refresh with skeleton loaders
- 💾 Local session persistence

## Tech Stack

- React (Hooks-based)
- CSS3 for styling
- Fetch API for backend communication
- LocalStorage for session management

## Prerequisites

- Node.js 14.x or higher
- npm 6.x or higher
- Running PulseAPP backend (local or remote)

## Local Setup

### 1. Clone and Install

```bash
git clone https://github.com/nebucthomas2003/discord-bot-frontend.git
cd discord-bot-frontend
npm install
```
